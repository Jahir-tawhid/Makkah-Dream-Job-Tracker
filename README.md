# 🕋 Makkah Dream Job Tracker

A sleek, responsive, and robust job application tracking web application built with **React**, **TypeScript**, and **Vite**. This application enables users to manage their career search efficiently by tracking applied positions, status updates, salary information, and application deadlines.

---

## ✨ Features

- **Job Application Management:** Easily add, track, and delete job applications.
- **Company Auto-Suggestions:** Integrated HTML5 `<datalist>` to autocomplete company names during entry.
- **Dynamic Search & Filtering:** Filter jobs instantly by company name or position title (case-insensitive).
- **Status Tracking:** Categorize job applications by status (`Applied`, `Interviewing`, `Offered`, `Rejected`).
- **Dashboard Analytics:** Live summary dashboard displaying total applications, status metrics, and unique applied positions.
- **Direct Application Links:** Included `Apply Now` action buttons to open original job post URLs in a new tab.
- **Data Persistence:** Utilizes browser `localStorage` to preserve job application records automatically across page refreshes.
- **Export & Reset Options:** Capability to export application data as JSON and reset state back to defaults.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 18+
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** CSS3 & Inline CSS / Flexbox Grid
- **Storage:** LocalStorage Web API
